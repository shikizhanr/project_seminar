# Habit Coach — интеллектуальный тренер по привычкам

Рабочий MVP системы для трекинга привычек, прогнозирования срывов, персональных
рекомендаций, анализа прогресса и дружеского рейтинга.

## Что реализовано

- регистрация, вход и JWT-авторизация;
- создание, редактирование и архивация привычек;
- ежедневные отметки с настроением, усилием и заметкой;
- ML-оценка риска пропуска с объясняющими факторами;
- локальная генерация персональных советов через Ollama (`qwen3:0.6b`);
- dashboard: регулярность, серии, 14-дневный тренд, XP и уровень;
- персональные мотивационные сообщения;
- подписки на друзей и закрытый рейтинг за 30 дней;
- Redis-кэш аналитики с безопасным fallback;
- мобильный Expo/React Native клиент;
- Telegram-бот для отметок и просмотра прогресса;
- Docker Compose, демоданные и API-тесты.

Подробности: [архитектура](docs/ARCHITECTURE.md).

## Быстрый запуск без Docker

Нужен Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev,bot]'
cp .env.example .env
python -m backend.demo_seed
uvicorn backend.app.main:app --reload
```

API: <http://localhost:8000>, Swagger: <http://localhost:8000/docs>.

Демо-вход: `demo@example.com` / `demo-password`.

## Docker

```bash
cp .env.example .env
docker compose up --build
docker compose exec backend python -m backend.demo_seed
```

PostgreSQL и Redis поднимаются автоматически. Для бота заполните в `.env`
`TELEGRAM_BOT_TOKEN`, `BOT_USER_EMAIL`, `BOT_USER_PASSWORD`, затем запустите:

```bash
docker compose --profile bot up bot
```

После первого `/start` Telegram-чат привязывается к демо-аккаунту, и становятся
доступны кнопки:

- `☀️ Сегодня` — дневной трекер с быстрыми отметками;
- `➕ Новая привычка` — мастер частоты и необязательного точного времени напоминания;
- `📈 Прогресс` — ML-риск и новый совет Ollama;
- `🗓 История` — календарь выполнений за 7, 30 или 90 дней;
- `⚙️ Мои привычки` — изменение напоминаний и архивация.

Время напоминания вводится вручную в формате `ЧЧ:ММ` (например, `07:35` или
`22:10`) и позднее изменяется в `⚙️ Мои привычки`. Напоминания отправляются ежедневно
в часовом поясе профиля, только если привычка ещё не выполнена. Для их работы процесс
Telegram-бота должен быть запущен.

## Мобильный клиент

```bash
cd mobile
npm install
EXPO_PUBLIC_API_URL=http://localhost:8000/api/v1 npm start
```

На физическом телефоне вместо `localhost` укажите LAN-адрес компьютера. В Android
эмуляторе обычно используется `http://10.0.2.2:8000/api/v1`.

## ML и Ollama

Система использует два независимых уровня интеллекта:

1. `HistGradientBoostingClassifier` прогнозирует вероятность пропуска по истории,
   серии, регулярности, сложности и дню недели.
2. Локальная Ollama-модель `qwen3:0.6b` выбирает стратегию поддержки для привычки с
   максимальным риском. Сам текст плана формируется приложением по строгому шаблону:
   фокус, причина выбора и одно конкретное действие на сегодня. Это не позволяет
   маленькой модели придумывать несвязанные советы. Данные не отправляются во внешний
   облачный API.

Установка лёгкой модели:

```bash
ollama pull qwen3:0.6b
```

Если Ollama выключена или не отвечает, dashboard автоматически выбирает стратегию
локальным алгоритмом. Поле `motivation_source` в API и экран прогресса бота показывают,
сработала Ollama или резервный алгоритм. Две одинаковые стратегии подряд для одной
привычки не выдаются.

Для новой привычки процент риска не показывается, пока не накоплено минимум пять
ожидаемых выполнений. Дни до создания привычки не считаются пропусками. Если привычка
уже выполнена сегодня, прогноз на текущий день заменяется статусом `выполнено`.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| POST | `/api/v1/auth/register` | регистрация |
| POST | `/api/v1/auth/login` | вход |
| GET/POST | `/api/v1/habits` | список/создание привычек |
| PATCH/DELETE | `/api/v1/habits/{id}` | изменение/архивация |
| PUT | `/api/v1/habits/{id}/check-ins` | создать или обновить отметку |
| GET | `/api/v1/habits/{id}/risk` | прогноз срыва |
| GET | `/api/v1/analytics/dashboard` | сводная аналитика |
| POST | `/api/v1/social/follow` | подписка на пользователя |
| GET | `/api/v1/social/leaderboard` | рейтинг социального круга |

## Ограничения MVP

Bootstrap-модель использует синтетическую выборку до накопления реальных данных.
Telegram-бот в демо-режиме работает от одного аккаунта из переменных окружения;
для публичного запуска нужен безопасный flow привязки Telegram-профиля. Социальное
сравнение намеренно показывает только добровольно добавленных пользователей.
